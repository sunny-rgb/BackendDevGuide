# 中大厂面经

## T0

### 1. 腾讯

#### 1.1 实习

腾讯实习面试的重点主要集中在 项目深度挖掘、算法能力考核、技术基础考察、场景题与优化思考、反问环节表现 等方面，具体如下：

- 项目深度挖掘 ：面试官会围绕项目背景、技术选型（如 Redis 数据结构选择、缓存架构设计）、具体实现细节（如页面 - 组件映射维护、分布式锁实现）、遇到的问题及解决方案（如任务调度效率优化、分片负载均衡）展开追问，要求候选人对项目有深入理解，并能清晰阐述优化思路
- 算法能力考核 ：常见题目包括快速排序、==LRU 实现==、==最长不重复子串（无重复字符的最长子串）==、螺旋矩阵、二叉树所有路径、==滑动窗口最大值==等，要求代码实现或口述思路，注重熟练度和优化（如从哈希表到排序的空间优化、动态规划到二分法的时间优化）
- 技术基础考察 ：覆盖多领域，包括：
  - Java 核心 ：HashMap 与 Hashtable 区别、多线程安全（synchronized、Lock、CAS）、JVM 内存管理（堆 / 栈 / 方法区）、线程池原理及使用场景
  - 操作系统 ：进程 / 线程 / 协程区别、进程间通信（共享内存、消息队列等）、虚拟内存管理、上下文切换开销
  - 计算机网络 ：TCP/UDP 区别、三次握手 / 四次挥手（如 TIME_WAIT 状态优化）、HTTP/HTTPS（加密方式、证书验证）、WebSocket 原理
  - 数据库与缓存 ：事务 ACID 特性、索引（B + 树时间复杂度、索引失效场景）、Redis 数据结构（ZSet、Pipeline）、缓存一致性（延迟双删、布隆过滤器）、分布式锁（Watchdog 续期机制）
- 场景题与优化思考 ：关注实际业务中的问题解决，如任务调度时单任务耗时过长的效率优化、分片后数据不均衡的负载处理、网络误差消除、高并发下的安全与性能（如 QPS 突增处理）
- 反问环节表现 ：通过询问部门业务方向、技术栈、职业发展建议等，考察候选人的主动性和对岗位的匹配度

#### 1.2 校招

腾讯校招面试重点可归纳为 技术基础、编程语言特性、算法与数据结构、项目经验、系统设计与场景题、非技术能力六大方向，具体如下：

- 一、技术基础
  
  覆盖操作系统、计算机网络、数据库等核心领域，考察对底层原理的理解：
  
  - 操作系统 ：进程与线程区别、进程通信方式（共享内存、管道等）、虚拟内存（页表、分段）、局部性原理等
  - 计算机网络 ：TCP 三次握手 / 四次挥手、HTTP/HTTPS 区别及加密原理、UDP 与 QUIC 协议特性、网络传输流程（DNS 解析、各层协议封装）等
  - 数据库 ：事务 ACID 特性、索引设计（B + 树、索引失效场景）、慢查询优化、MongoDB 与 Redis 选型差异等
  
- 二、编程语言特性
  
  根据岗位语言不同，侧重考察核心机制：
  
  - Java ：JVM（内存模型、垃圾回收）、并发（synchronized、Lock、信号量）、集合类底层原理
  - Go ：channel 特性（读写规则）、GMP 模型、defer 机制、微服务框架设计（Etcd 服务注册、gRPC 调用）
  
- 三、算法与数据结构
  
  高频考察基础算法实现及数据结构原理：
  
  - 算法题 ：括号匹配、合并有序数组、二分查找、LRU 缓存、链表反转、滑动窗口中位数等，要求时间 / 空间复杂度优化
  - 数据结构 ：哈希表（冲突解决）、堆（最大堆实现）、B 树 / B + 树（索引应用）、红黑树（平衡特性）。
  
- 四、项目经验
  
  重点追问技术细节与问题解决能力：
  
  - 技术选型 ：如 MongoDB 替代 Redis 的原因（条件查询优势）、游戏服务器未容器化的考量（延迟敏感）
  - 问题解决 ：索引失效（左模糊匹配、类型转换）、慢查询优化、分布式锁（防重入）、幂等性设计（抽奖积分扣减）
  - 架构设计 ：微服务（Etcd 服务注册、Service Mesh）、自动扩缩容（跨云服务兼容）、定时系统（Redis ZSet + 负载均衡）
  
- 五、系统设计与场景题
  
  考察复杂场景下的设计能力：
  
  - 高并发 / 高可用 ：UDP 实现可靠传输（ACK 机制、重传、排序）、多实例负载均衡（哈希分配）、容灾设计（Worker 主从架构）
  - 分布式系统 ：Etcd 选主（Lease 机制）、定时服务设计（分块处理、时间精度）、文件传输流程（Socket 通信、协议完整性校验）
  
- 六、非技术能力
  
  关注软技能与职业适配性：
  
  - 团队协作 ：沟通重要性（早会制度）、职责明确（上级指派 + 主动确认）、信任建立（互担责任）
  - 职业认知 ：领导能力（进度把控、任务分配）、3 年职业规划（技术深度 + 团队管理）、学习与工作差异（实践导向、沟通复杂度）

### 2. 字节跳动

#### 2.1 实习

字节跳动实习面试的重点可总结为以下方面 ：

- 一、技术基础与八股文考察
  - 计算机基础 ：涵盖操作系统（虚拟内存、进程内存区块、单核并发）、计算机网络（TCP/UDP 区别、HTTP 状态码、DNS 排查、HTTPS 重定向）、JVM（内存结构、GC 机制）、Java（NIO 执行流程、HashMap 与 ConcurrentHashMap 区别）等核心知识点
  - 数据库与中间件 ：MySQL（索引结构、MVCC 实现、分库分表）、Redis（主从复制、分布式锁、过期时间实现、数据结构）、消息队列（Kafka/RabbitMQ 的消息幂等、积压处理、选型对比、延迟队列）是高频考点
  - 设计模式与架构 ：策略模式、单例模式（双检锁）、分布式架构（高并发、高可用、缓存一致性）等设计思想需深入理解
- 二、项目深挖与场景设计
  - 项目细节 ：重点追问项目的技术选型（如 Redis 与 MySQL 的冷热数据存储分工、消息队列选择）、实现逻辑（定时任务调度逻辑、语音转文本流程）、性能优化（压测、分库分表）及问题解决（消息积压处理、一致性保证）
  - 场景设计 ：需具备场景题应对能力，如设计限流器（固定窗口、ZSet 结构）、消息顺序消费策略、模型升级方案、分布式 ID 生成等
- 三、算法与编程能力
  - 算法题 ：高频题目包括最长递增子序列、反转链表 II、最大连续子数组和、最长重合子串、买卖股票最佳时机、逆波兰表达式等，强调代码正确性、逻辑清晰及规范（如变量命名）
  - 编程题 ：需掌握并发安全 LRU 实现、二叉树路径匹配链表等，要求思路清晰且具备调试能力
- 四、软技能与表达技巧
  - 项目叙述 ：需结构化表达，主动概述项目整体（如 “高精准高可用实现”），突出重难点，避免流水账式陈述
  - 沟通与应变 ：回答时先抓住问题核心，避免过度展开；面对追问保持逻辑清晰，及时调整节奏
- 五、其他注意事项
  - 语言与技术栈 ：根据岗位方向（如 Java/Go）侧重考察对应语言特性（如 Go 的 GMP 模型、Channel 底层实现）
  - 业务匹配 ：部分岗位（如游戏后端）更关注系统知识（操作系统、网络），需结合业务场景针对性准备

#### 2.2 校招

字节跳动校招面试重点可总结为 项目深度、基础知识扎实度、算法能力、系统设计思维及表达沟通能力 ，具体如下：

- 一、项目深度考察

  面试官会围绕简历中的项目展开详细追问，重点关注：

  - 技术选型与设计思路 ：如为何选择分布式限流器而非单机限流器、为何不用现有调度框架（如 XXL-Job）、如何解决 Redis HotKey 问题等
  - 细节与优化 ：例如任务调度的具体实现（如 Worker 层与 Server 层交互逻辑）、数据一致性保障（如 Redis 与 MySQL 的缓存一致性）、高并发场景下的性能优化（如分库分表、冷热数据分离）等
  - 难点与解决 ：需清晰描述开发中遇到的问题（如高负载、高精准调度）及具体解决方案（如分布式锁、任务状态治理）

- 二、基础知识扎实度（八股）

  覆盖计算机网络、数据库、操作系统、编程语言特性等，具体包括：

  - 计算机网络 ：TCP/UDP 区别、三次握手四次挥手原理、HTTP/HTTPS 差异及握手过程、QUIC 协议了解
  - 数据库 ：MySQL 的索引（B + 树、联合索引最左匹配）、事务隔离级别（MVCC 解决不可重复读）、RedoLog 与 BinLog 区别；Redis 的数据结构（Zset、String）、过期键淘汰策略、延迟队列设计
  - 操作系统 ：进程 / 线程 / 协程区别、死锁条件与预防、线程调度算法、内存管理机制
  - 编程语言特性 ：Go 的协程（有栈 / 无栈）、Java 的并发（ConcurrentHashMap、synchronized）、C++ 智能指针等

- 三、算法能力

  几乎所有面试均包含算法题，题目类型覆盖链表操作（反转链表）、动态规划（最长无重复子串、最大子数组和）、字符串处理（数字转 IP 地址）、二叉树遍历（路径匹配）等，要求：

  - 熟练掌握常见数据结构（链表、数组、树、哈希表）及算法（双指针、回溯、DFS/BFS）。
  - 注意边界条件（如 0000 转 IP 地址）、代码效率（如避免超时）

- 四、系统设计与场景题

  部分岗位（如后端开发）会考察系统设计能力，涉及：

  - 高并发场景（秒杀、抢红包）的稳定性设计（如 Redis Zset 维护用户视频列表、消息队列解耦）。
  - 分布式系统设计（如定时微服务的任务调度、RPC 服务的模型热加载）

- 五、表达与沟通能力

  强调 结构化表达 ：先回答核心结论，再展开细节；避免冗长，若展开内容非面试官关注，及时停止。同时需清晰传达项目整体逻辑，避免面试官陷入细节

### 3. 阿里

#### 3.1 实习

总结阿里巴巴实习面试的重点及对应 tag 如下：

- 一、项目经验深度考察（tag：项目深度）

  面试官会围绕项目 技术细节、设计逻辑、优化思路 进行高频追问，包括技术选型原因、遇到的问题及解决方案、实际应用场景扩展等。例如：

  - 饿了么一面详细追问 XTimer 项目中 Redis 的 Key/Value 设计、线程池参数配置、OOM 处理等细节
  - 大文娱一面要求解释项目模块（时间块、调度块、触发块）的具体作用及任务唤醒机制
  - 淘天二面讨论缓存一致性问题的解决方案及分布式锁优化
  - 蚂蚁二面针对商家数据质量管控、缓存更新策略等项目实际问题进行扩展提问

- 二、Java 核心技术（tag：Java 核心）

  覆盖 语言特性、JVM、多线程、框架原理 等，重点考察底层原理和实际应用：

  - 集合类：HashMap（链表转红黑树阈值）、ConcurrentHashMap（CAS+Synchronized）
  - JVM：内存结构（方法区与元数据区关系）、垃圾回收算法（标记 - 清除、复制、标记 - 整理）
  - 多线程：ThreadLocal（内存泄漏、弱引用）、线程池（核心参数、拒绝策略）、锁机制（ReentrantLock、AQS）
  - Spring：IOC（依赖注入）、AOP（动态代理）、自动配置原理（@EnableAutoConfiguration）
  - 新增特性：JDK21 虚拟线程与传统线程的区别

- 三、数据库与缓存（tag：数据库与缓存）

  聚焦 MySQL 索引与事务、Redis 数据结构及一致性 ，强调实际场景应用：

  - MySQL：索引原理（B + 树）、事务隔离级别（幻读）、锁机制（乐观锁 / 悲观锁、行锁 / 表锁）
  - Redis：数据结构（Zset 用于定时任务排序）、缓存问题（穿透 / 击穿 / 雪崩）、双写一致性（先更新 DB 后删缓存、版本号控制）
  - 扩展设计：分库分表（按时间 / 用户 ID 分片）、冷热数据分区（Redis 存热数据，DB 存冷数据）

- 四、计算机网络与操作系统（tag：网络与 OS）

  基础协议与系统机制是必考点，侧重理解与场景结合：

  - 网络：TCP 三次握手 / 四次挥手（状态流转）、HTTP 状态码（1xx-5xx）、IO 多路复用（epoll 红黑树 + 链表实现）
  - 操作系统：进程与线程区别（资源分配 / 执行单位）、线程池参数（核心线程数、拒绝策略）

- 五、场景题与系统设计（tag：场景设计）

  考察 高并发、海量数据、分布式系统 的设计能力，要求从架构师视角思考：

  - 高并发：秒杀场景限流（分布式锁）、5000 万单系统动态分桶
  - 海量数据：大文件处理（分块 + 多线程统计）、日志查询（日期 + 用户过滤）
  - 分布式：分布式锁（互斥、可重入、死锁避免）、容灾切换（Haproxy + 人工同步）

- 六、算法与代码能力（tag：算法编码）

  部分面试含 代码题 （如最大数、交替输出），要求逻辑清晰、编码速度快，同时需掌握常见算法思想（如布隆过滤器、雪花算法）

- 七、软技能与学习能力（tag：软技能）

  关注 项目反思、技术学习路径、问题解决思路 ，面试官希望候选人展现深度思考与成长潜力：

  - 项目反思：如蚂蚁二面建议 “多思考项目优化点，关注用户体验”；大文娱一面强调 “扩展业务回调流程的思考”
  - 学习路径：需结合官方文档、实践验证、问题解决，展现主动学习能力

#### 3.2 校招

阿里巴巴校招面试重点可归纳为以下核心方向，结合不同部门面经整理如下：

- 一、项目经验与细节深挖
  - 核心要求 ：需详细介绍项目背景、技术栈、个人职责、技术难点及解决方案，面试官会针对项目中的具体设计（如分布式锁、分表策略、任务调度等）深入追问。
  - 典型场景 ：包括异步任务框架（如 AsyncFlow）、定时微服务、判题系统等，涉及存储设计、异常处理、并发控制、数据一致性等技术细节。
  - tag 标注 ：项目经验、项目细节、技术细节
- 二、基础知识与原理掌握
  - 计算机基础 ：涵盖负数补码表示、小数精确存储、进程调度算法、内存分配算法、死锁避免等。
  - 网络知识 ：TCP 三次握手 / 四次挥手、可靠性保证（滑动窗口、重传机制）、HTTP 状态码、HTTPS 加密原理等。
  - 数据库知识 ：MySQL 的 B + 树索引、事务隔离级别（如可重复读）、MVCC 机制、分库分表、分布式锁实现（Redis）、数据一致性保证等。
  - Java 基础 ：JVM 内存结构（堆、栈、方法区）、垃圾回收算法（标记 - 清除 / 复制 / 整理）、多线程（线程池参数、锁升级、ThreadLocal）、集合类（HashMap、ArrayList）等。
  - tag 标注 ：计算机基础、网络知识、数据库、Java 基础
- 三、算法与编程能力
  - 算法题 ：常见题目包括鸡蛋楼层问题、序列化反序列化二叉搜索树、LRU 缓存、合并区间、连续子数组最大和等，需分析时间复杂度及优化思路。
  - 编程实践 ：如 Go 语言协程交替打印、大数之和实现、单例模式编写等，考察代码逻辑与边界处理。
  - tag 标注 ：算法能力、编程能力
- 四、场景设计与实际应用
  - 高并发与海量数据 ：涉及动态分桶、冷热数据分区、缓存穿透 / 击穿解决（Redis）、分布式事务（2PC/3PC）、流量控制设计等。
  - 系统设计 ：如定时任务平台（时间块划分、worker 负载均衡）、异步任务调度（拒绝策略、重试机制）、日志系统（实时性与准确性平衡）等。
  - tag 标注 ：场景设计、实际开发应用、高并发
- 五、个人背景与综合能力
  - 个人经历 ：包括教育背景（院校、专业）、实习经历（职责、成果）、科研成果（论文、项目）等。
  - 综合表现 ：关注表达流畅度、知识深度与广度、反思能力（如项目优化思考）、职业规划（工作地点倾向）等。
  - tag 标注 ：个人背景、综合表现、职业规划

### 4. 小红书

#### 4.1 实习

小红书实习面试重点可总结为 技术基础考核、项目 / 实习深度追问、算法编程能力考察、岗位适配性评估 四大方向，以下是具体内容及对应 tag：

- 一、技术基础考核（tag: 技术基础）
  - 计算机网络 ：高频问题包括 TCP 与 UDP 区别、流量控制机制（如滑动窗口）、HTTP 状态码（如 200/404/50X 含义）、IO 多路复用（select/poll/epoll）
  - 操作系统 ：进程与线程区别、线程栈 / 堆的共享性、TLB 作用、零拷贝实现、BIO/NIO 差异等

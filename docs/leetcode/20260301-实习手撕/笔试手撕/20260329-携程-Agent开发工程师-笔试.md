## 【携程】【2026-03-12】第二题-拆盲盒

#### 实现思路

奇偶素数 + 公式拆分

#### 题目描述

给定一个正整数 n 与一个正整数 m。你需要把 n 拆分为若干个素数之和（可以重复选择同一个素数），设最终使用的素数个数为 k。

同时要求：所选素数中奇素数（除 2 以外的素数）的数量必须是 m 的正整数倍（不能为 0）。

请在满足约束的前提下，使 k 最大化，并输出这个最大的 k。若不存在任何满足要求的拆分方案，输出 −1。

**名词解释：**

**素数**：大于 11 且只有 11 与其本身两个正因子的整数。**奇素数**：除 22 以外的素数。

#### 输入描述

每个测试文件均包含多组测试数据。

第一行输入一个整数 t(1≤t≤104)*t*(1≤*t*≤104) 表示测试数据组数，每组测试数据描述如下：

在一行上输入两个整数 n,m(2≤n≤1018,1≤m≤1018)*n*,*m*(2≤*n*≤1018,1≤*m*≤1018)。

#### 输出描述

对于每一组测试数据，新起一行输出一个整数：满足要求的最大的素数个数 *k*；若无解，则输出 −1。

#### 样例

```
输入
4
6 2
2 1
30 4
1000000000000 1

输出
2
-1
13
499999999999
```

#### 代码实现

```go
package main

import (
    "bufio"
    "os"
    "fmt"
)

func calculate(n, m int) int {
    // 1: 不是素数
    // 2: 偶素数 a
    // 3: 奇素数 b
    // 核心问题: n = a * 2 + b * 3, 其中 a + b = K
    // 变形: (n - b) = 2 * (a + b)
    // 所以最后, k = (a + b) = (n - b) / 2

    // 这里 multi 为什么只能取值 1 和 2？
    // 基于贪心思想，3 一定比 2 大，所以取 3 的个数越少越好
    // multi 代表取 1个 3，还是取 2个 3
    for multi := 1; multi <= 2; multi++ {
        b := m * multi

        if 3*b > n {
            break
        }

        if (n - b) % 2 == 0 {
            return (n - b) / 2
        }
    }

    return -1
}

func main() {
    reader := bufio.NewReader(os.Stdin)

    var count int
    fmt.Fscan(reader, &count)

    for i := 0; i < count; i++ {
        var n, m int
        fmt.Fscan(reader, &n, &m)

        res := calculate(n, m)
        
        fmt.Println(res)
    }
}
```

## 【携程】【2026-03-12】第三题-天才的数列切割

#### 实现思路

前缀和 + 二分查找 + 递归

#### 题目描述

给定一个长度为 n*n* 的数组 {a1,a2,...,an}{*a*1,*a*2,...,*a**n*}。你将对数组进行若干次”切割”操作，操作规则如下：

一开始，数组段集合仅包含整段 [1,n][1,*n*]。

每次操作，必须从”当前数组段集合”中选择一段完整的数组段 [l,r][*l*,*r*]（该段长度需严格大于 22），然后选择一个位置 mid(l<mid≤r)*mi**d*(*l*<*mi**d*≤*r*)，若满足：

∑i=lmid−1ai=∑i=midrai∑*i*=*l**mi**d*−1*a**i*=∑*i*=*mi**d**r**a**i*

则可以把该数组段分成两段 [l,mid−1][*l*,*mi**d*−1] 与 [mid,r][*mi**d*,*r*]，并以这两段替换原来的 [l,r][*l*,*r*]，继续加入到数组段集合中。

一旦一个数组段被切割，它将从集合中移除并被两个新的子段取代。你只能选择当前集合中存在的完整段进行下一次切割，不允许跨越段边界或在段内截取任意子段进行操作。

所有区间均以原数组的下标表示，不进行重新编号；切割后得到的两个区间互不重叠，且并集为原区间。请你计算，在最优策略下，总共最多能进行多少次切割。

#### 输入描述

第一行输入一个整数 n(1≤n≤106)*n*(1≤*n*≤106) 表示数组的长度。

第二行输入 n*n* 个整数 a1,a2,...,an(1≤ai≤109)*a*1,*a*2,...,*a**n*(1≤*a**i*≤109) 表示数组中的元素。

#### 输出描述

输出一个整数，表示最多的切割次数，若不存在任何合法的切割方案，输出 00。

#### 样例

```
输入
6
1 2 1 1 1 2

输出
2
```

#### **样例解释**

对全段 [1,6]，可在 mid=4*mi**d*=4 处切割，因为 1+2+1=1+1+21+2+1=1+1+2。得到 [1,3][1,3] 与 [4,6][4,6]。随后 [4,6][4,6] 在 mid=6*mi**d*=6 处再次切割，因为 1+1=21+1=2。总共进行了 22 次切割。

#### 代码实现

```go
package main

import (
    "bufio"
    "os"
    "strings"
    "strconv"
    "fmt"
    "sort"
)

var prefix []int

func split(l, r int) int {
    // 段长度必须严格大于 2
    if r-l+1 <= 2 {
        return 0
    }

    S := prefix[r] - prefix[l-1]

    // 如果不能被 2 整除，自然就不能完美切割成两段
    if S % 2 != 0 {
        return 0
    }

    // 开始计算
    target := prefix[l-1] + S/2

    pos := sort.Search(r-l, func(i int) bool {
        return prefix[l+i] >= target
    }) + l

    if pos < r && prefix[pos] == target {
        return 1 + split(l, pos) + split(pos+1, r)
    }

    return 0
}

func main() {
    reader := bufio.NewReader(os.Stdin)

    line1, _ := reader.ReadString('\n')
    line2, _ := reader.ReadString('\n')

    desc := strings.Fields(line1)
    n, _ := strconv.Atoi(desc[0])

    numsStr := strings.Fields(line2)

    // 构造前缀和
    prefix = make([]int, n+1)
    for i := 0; i < n; i++ {
        val, _ := strconv.Atoi(numsStr[i])
        prefix[i+1] = prefix[i] + val
    }

    res := split(1, n)

    fmt.Println(res)
}
```

## 第二题-最短连续子序列

#### 题目描述

在一个数组中，找出最短的连续子序列，要求：这个子序列的和大于给定值 target

#### 样例

```
输入
7（target）
6（n)
2 1 3 2 4 3

输出
2
```

#### 代码实现

```go
package main

import (
    "bufio"
    "os"
    "fmt"
)

func calculate(nums []int, target, n int) int {
    if len(nums) == 0 || n <= 0 {
        return 0
    }

    minLen := n + 1

    left := 0

    sum := nums[left]

    for right := 1; right < n; right ++ {
        sum += nums[right]

        currentLen := right - left + 1
        if sum >= target && minLen >= currentLen {
            for sum >= target {
                minLen = right - left + 1
                sum -= nums[left]
                left++
            }
        }

    }

    if minLen == n + 1 {
        return 0
    }

    return minLen
}

func main() {
    reader := bufio.NewReader(os.Stdin)
    var target, n int
    fmt.Fscan(reader, &target, &n)

    nums := make([]int, n)

    for i := 0; i < n; i++ {
        fmt.Fscan(reader, &nums[i])
    }

    res := calculate(nums, target, n)

    fmt.Println(res)
}
```

## 第三题-机器人路径条数

#### 题目描述

计算机器人从 (0, 0) - (m-1, n-1) 的路径条数，其中 "1"表示障碍物，"0"表示空地。机器人只能往下或往右走。

#### 输出描述

输出一个整数，表示最多的路径条数，若不存在则输出 0。

#### 样例

```
输入
3 3
0 0 0
0 1 0
0 0 0

输出
2
```

#### 笔试代码实现(AC 60%，代码正确，但是超时)

这种解法一个很严重的问题是，对于较大的网格（如 m=20, n=20），递归会指数级爆炸，可能超时或栈溢出。

```go
package main

import (
    "bufio"
    "os"
    "fmt"
)

func calculate(nums [][]int, m, n int) int {
    res := 0

    var dfs func(i, j int)
    dfs = func(i, j int) {
        if i >= m || j >= n || nums[i][j] != 0 {
            return
        }

        if i == m-1 && j == n-1 {
            res++
            return
        }

        bfs(i+1, j)
        bfs(i, j+1)
    }

    bfs(0, 0)

    return res
}

func main() {
    reader := bufio.NewReader(os.Stdin)

    var m, n int
    fmt.Fscan(reader, &m, &n)

    nums := make([][]int, m)
    for i := 0; i < m; i++ {
        numsRow := make([]int, n)
        for j := 0; j < n; j++ {
            fmt.Fscan(reader, &numsRow[j])
        }
        nums[i] = numsRow
    }

    res := calculate(nums, m, n)

    fmt.Println(res)
}
```

### 优化实现-动态规划

```go
func calculate(nums [][]int, m, n int) int {
    if nums[0][0] == 1 || nums[m-1][n-1] == 1 {
        return 0
    }
    
    dp := make([][]int, m)
    for i := 0; i < m; i++ {
        dp[i] = make([]int, n)
    }
    
    dp[0][0] = 1
    for i := 0; i < m; i++ {
        for j := 0; j < n; j++ {
            if nums[i][j] == 1 {
                dp[i][j] = 0
                continue
            }
            if i > 0 {
                dp[i][j] += dp[i-1][j]
            }
            if j > 0 {
                dp[i][j] += dp[i][j-1]
            }
        }
    }
    return dp[m-1][n-1]
}
```

openclaw

如果把别的 agent 当成"一个 CLI 工具"，openclaw 更像一个 24 小时在线的家庭网关——WhatsApp、Telegram、Discord 这些聊天工具，桌面端、移动端、Web 控制台，全都连到一个长驻的 Gateway 进程上，由它统一路由到内嵌的编码 agent。沙箱是默认关闭、主动开启的（Docker / Podman / SSH / OpenShell 任选），这点跟 codex 那种"开机就锁死"的取向正好相反。

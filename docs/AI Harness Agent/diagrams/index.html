六个 Harness，六种架构

把 openclaw、hermes-agent、claude-code、codex、pi、deepseek-harness 这六个仓库的架构各画一张图。每张图都围绕那一家最锋利的差异点展开——单看一张图就能和别家区分开。

01 / 06

openclaw

Personal AI Gateway

如果别的 agent 是"CLI 工具"，openclaw 更像一个 24 小时在线的家庭网关——所有聊天平台、桌面/移动 app、Web 控制台都连到一个长驻 Gateway，再由它统一调度底下的编码 agent。沙箱默认是关的（要开就接 Docker/SSH/OpenShell 之一），这点和 codex 那种"开机就锁死"的取向正好相反。

架构 · TS · pnpm monorepo 沙箱 · opt-in · Docker/SSH 协议 · MIT

02 / 06

hermes-agent

Self-Improving Personal Agent

一个 Python 项目，UI 面多到有点夸张——CLI、TUI、Electron 桌面端、Web、二十多个聊天平台、ACP 协议直接当 IDE 服务端——所有入口共享同一套对话循环。最特别的是"自我进化"：agent 自己写技能文件，再由一个独立的小模型当 curator 审一遍、决定要不要让技能生效，等于让 agent 给自己做 Code Review。

架构 · Python 3.11 · TS UIs · native FTS5 沙箱 · 7 backends 协议 · MIT
中心
Conversation Loop Curator (aux model) MEMORY/USER

03 / 06

claude-code

Anthropic's Coding Agent

Anthropic 出的 CLI，二进制本身是闭源的，开源仓库只是它的扩展面——plugin、hooks、skills、sub-agents、slash commands 全用 JSON 或 Markdown 描述，几乎零代码就能扩展。真正和别人拉开差距的是企业部署：通过 MDM（Jamf、Intune、ADMX、Group Policy）把"能用哪些模型、能装哪些插件"这类策略下发到全公司员工的机器上，是为 ToB 场景量身设计的能力。

架构 · closed binary · open extension 沙箱 · app-level · opt-in 协议 · Proprietary
中心

04 / 06

codex

OpenAI's Coding Agent

OpenAI 的 Rust 项目，2024 edition 的 workspace 拆了 130 多个 crate，codex-core 是那颗心脏。面试时最值得拿出来讲的是它的安全设计——Linux、macOS、Windows 三个 OS 各有自己一套原生沙箱实现（seccomp+bwrap / sandbox-exec / Job+ACL+WFP），并且在 OS 沙箱之上还多套了一层独立的 execpolicy DSL，把"怎么隔离"和"该不该允许"两件事明确拆开。

架构 · Rust 2024 · 130 crates 沙箱 · always-on · per-OS native 协议 · Apache-2.0
中心
codex-core execpolicy DSL Multi-agent namespaces

05 / 06

pi

Self-Extensible Coding Agent

一个 npm 上的 TS monorepo，10 个包，pi-agent-core 居中。两个最有辨识度的设计："self-extension"——agent 在运行时能写自己的扩展并注册回工具表；以及一个反主流的选择——故意不做自己的权限系统，沙箱完全推给宿主层（自带 Gondolin micro-VM，或者外接 Docker / OpenShell 三选一）。

06 / 06

deepseek-harness

Agent Meta-Framework

把 Koishi 生态里的 Cordis 框架直接 vendor 进来搭骨架——一句话讲就是"什么都是插件"：调 LLM、注册工具、起沙箱都是插件，全挂到同一个 ctx 上。最值得在面试里聊的是它的 Session Event Log：所有事件先写日志，连发给模型的上下文都是从这份日志实时 derive 出来的，并且这件事由 TypeScript 的 SessionEventMap 在编译期强制保证，想绕都绕不过。

架构 · TS · vendored Cordis 沙箱 · Landlock/Seatbelt/ACL 版本 · 0.1.1-rc.1
中心
Cordis plugin tree SessionEventMap sub-agent backends

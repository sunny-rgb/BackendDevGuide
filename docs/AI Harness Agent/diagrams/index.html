六个 Harness，六种架构

把 openclaw、hermes-agent、claude-code、codex、pi、deepseek-harness 这六个仓库的架构各画一张图。每张图都围绕那一家最锋利的差异点展开——单看一张图就能和别家区分开。

openclaw

Personal AI Gateway

一个常驻 Gateway 进程居中，30+ 消息通道、桌面/移动 app、Web 控制 UI、内嵌编码 agent 全挂在它身上。沙箱默认关闭，可插拔（Docker / Podman / SSH / OpenShell）。

hermes-agent

Self-Improving Personal Agent

一个 Python 写的多入口个人 agent。同一套对话循环跑在 CLI / TUI / Electron / Web / 20+ 消息通道 / ACP IDE 服务端上。独特的"自我进化"循环——agent 写自己的技能，curator 用辅助模型维护它们。

架构 · Python 3.11 · TS UIs · native FTS5 沙箱 · 7 backends 协议 · MIT

claude-code

Anthropic's Coding Agent

闭源的 CLI 二进制居中。本仓库只是扩展面：plugin marketplace、hooks、skills、sub-agents、slash commands 全用 JSON / Markdown 描述。最强的是企业部署故事——MDM（Jamf / Intune / ADMX / Group Policy）做强制策略。

codex

OpenAI's Coding Agent

Rust 2024 workspace（130+ crate），codex-core 居中。三个 OS 各一套原生沙箱（Linux seccomp+bwrap / macOS sandbox-exec / Windows Job+ACL+WFP）。execpolicy 是 OS 沙箱之上的独立声明式策略层。`WireApi::Responses` 是唯一合法 wire。

架构 · Rust 2024 · 130 crates 沙箱 · always-on · per-OS native 协议 · Apache-2.0

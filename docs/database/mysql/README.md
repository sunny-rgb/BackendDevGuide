# MySQL

## 1. MySQL简介

市面上常用数据库有MySQL、Oracle、SQLServer等。其中，MySQL是免费的，在互联网公司中使用率非常高，社区活跃，且学习成本相对较低，同学们可以主要学习**MySQL数据库**。在完成MySQL学习后，其它数据库学习速度也会非常快。
